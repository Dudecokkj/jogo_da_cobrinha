# Jogo da Cobrinha

Clássico jogo da cobrinha feito com HTML, CSS e JavaScript puros, desenhado em `<canvas>`. O recorde fica salvo no navegador.

## Como jogar

Abra o `index.html` no navegador (duplo clique).

- **Teclado:** setas ou WASD. O jogo começa na primeira tecla.
- **Celular:** use os botões na tela.
- Coma os quadrados vermelhos para crescer e ganhar pontos.
- O jogo acaba ao bater na parede ou no próprio corpo.

## Ajustes rápidos

No começo do `game.js`:

- `VELOCIDADE_MS`: menor = mais rápido
- `TAMANHO`: tamanho de cada célula (o canvas deve ser múltiplo dele)

## Ideias para evoluir
